Game class for the Game 21 (Blackjack) implementation

This class handles all game logic for the Game 21 card game including dealing cards, managing player and dealer actions, calculating scores, and determining the game winner.

Calculate the score of a hand

private calculateHandScore(CardHand $hand) : int

Adds up the values of all cards in the hand. Number cards are worth their face value, face cards are worth 10, and Aces can be worth either 1 or 14 (calculated automatically to maximize the hand score without exceeding 21).
